# Textura terrestre

`tierra-blue-marble.jpg` es una copia sin modificar del mosaico global Blue Marble: Next Generation de julio de 2004, NASA Earth Observatory (5400 × 2700 píxeles).

- Página de origen y descargas: https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-map/
- Archivo original: https://assets.science.nasa.gov/content/dam/science/esd/eo/images/bmng/bmng-base/july/world.200407.3x5400x2700.jpg
- Crédito: NASA Earth Observatory, Blue Marble: Next Generation.
- Uso: textura visual del globo de Inicio. No representa observaciones NISAR ni el estado actual del planeta.

Las estrellas y el modelo de NISAR se generan con geometría y shaders propios. El modelo toma como referencia visual la descripción pública de NASA/JPL: https://science.nasa.gov/mission/nisar/about-the-satellite/. Su escala, orientación, velocidad y recorrido son ilustrativos; no son un modelo de ingeniería ni una propagación orbital.
